## Draft

How to read the collection. Every page in the collection has three sections: Research, Draft, and References. Each section has a different job.

The Research section is the evidence. Each fact there carries a source. The source is a URL you can open. You can check the source and see what it actually says. If the source says "lunatic asylums were first established in Britain in the mid-19th century," then that is what the record says. If the source does not say something, the page should not say it either.

The Draft section is the story. It shows what the record says about the topic. It names the facts in order. It tells you what the record does not say. A good Draft does not pretend the record is complete. It names the gaps.

The References section is the citation ladder. Each entry has a name, a URL, and a tag. The tag tells you what kind of source it is: Primary, Scholarly, Institutional, Reference, or Web. A Primary source is the original record. An Institutional source is a museum, archive, or government guide.

Here is how to read a page. Start with the Research. Check each source. Then read the Draft. Follow the facts. Then go to the References and check the citations. If a fact feels shaky, find the matching reference and open the URL. One more thing: the tags. The References section tags each source. A Primary tag means the source is the original record. A Scholarly tag means the source is a peer-reviewed book or article. An Institutional tag means the source is a museum, archive, or government guide. The tag tells you how much weight the source carries. You can use the tag to judge the fact.

That is how you read the collection.

You can walk through the collection. You can look at the sources. You can disagree with the interpretation. That is the point.
