## Draft

A guide page is a tool. The tool shows how to read one type of page in the collection. It does not show what the record does not say.

A guide page is meta. It does not tell you about the mind. It tells you how to read the page that does. If you are trying to understand a time-band page, the guide page shows you the method. If you are trying to understand a place page, the guide page shows you the method.

Each guide page follows the same shape. It names the page type. It explains what that page type shows and what it does not show. It gives a concrete example. It tells you how to check the sources.

Start with the Research section. Each fact carries a source. You can open the source and check it. The guide page uses the same evidence rules as every other page. It does not get a pass because it is a guide.

Here is a concrete example. The guide for time-band pages walks through the 19th-century band. It names the County Asylums Act of 1808, the 1845 Acts, and the 1890 Act. It shows you how to follow the dated facts and check each source. That is the method, applied to one example.

Here is how to apply the method. Take the guide for time-band pages. It shows you how to follow the dated facts and check each source. Now take a time-band page and apply the method. Follow the dated facts. Check each source. Notice where the record goes quiet. If the page does not follow the method, the page is not doing its job. The guide is the standard. The page is the test.

That is how you read a guide page: take the method, apply it to the page type, and check the example.
