# Q10 — How to Read a Place Page

> *A place page is a map. The map shows what the record says about a specific place. The map does not show what the record does not say. That is the point of this page: the place page is a map, and the map is limited.*

## Draft

A place page is a map. The map shows what the record says about a specific place. The map does not show what the record does not say.

A place page has a scope. The scope is the region the page covers. A good place page names the scope and stays inside it. It does not let one region stand for another. If the page is about Mesopotamia, it does not claim to explain all of West Asia. If the page is about Egypt, it does not claim to explain all of North Africa.

Here is how you check the scope. Take a fact from the Draft. Find the place. Check the source. Does the source cover that place? If yes, the fact holds. If the source covers a different place, the page should say so.

The National Archives guide covers Britain. It says lunatic asylums were first established in Britain in the mid-19th century. The scope is Britain. The guide does not cover France, or the colonies, or the United States. A place page about Britain can use the guide. A place page about France cannot.

That is the rule: the source must match the place. If the source is about Britain, the page is about Britain. If the page wants to cover France, it needs a source about France.

Here is what to do when the source covers a different place. If the page is about France and the source is about Britain, the page cannot use that source. It needs a source about France. If no source about France exists, the page should say so. It should not stretch the British source to cover France. The scope is the boundary. The source must match the boundary.

One more check: the boundary. The scope is the boundary. The source must match the boundary. If the page is about Mesopotamia, it does not claim to explain all of West Asia. If the page is about Egypt, it does not claim to explain all of North Africa. The boundary is the point.

That is how you check the scope of a place page: find the place, check the source, and notice where the map runs out.
