# Q11 — How to Read a Route Page

> *A route page is a path. The path shows what the record says about a specific route. The path does not show what the record does not say. That is the point of this page: the route page is a path, and the path is limited.*

## Draft

A route page is a path. The path shows how an idea, a law, or a practice moved from one place or group to another. The path does not show what the record does not say.

The key question on a route page is: what is the mechanism? A route is not "influence." Influence is a guess. A mechanism is a named thing: a person who traveled, a ship that carried a book, a treaty that copied a law, a journal that published a paper. If the record cannot name the mechanism, the page says so.

Here is how you check the mechanism. Take a claim from the Draft. Find the mechanism. Check the source. Does the source name the mechanism? If yes, the route holds. If the source only says "the idea spread," the page should say so. It should not pretend the spread is proven.

The National Archives guide names the laws behind the asylum route: the County Asylums Act of 1808, the 1845 Acts, the 1890 Act. Those are named mechanisms. The route page can use them. But the guide does not name the mechanism by which the asylum moved to the colonies. So a route page about the colonial asylum needs a different source.

Here is what to do when the route is a guess. If the source only says "the idea spread" and does not name the mechanism, the page should say so. It should not pretend the spread is proven. It can say: "the record does not name the mechanism by which the idea moved." That is honest. It is better than a smooth guess. The route page names the guess and does not hide it.

One more check: the named thing. A route page names the mechanism. The mechanism is a named thing: a person who traveled, a ship that carried a book, a treaty that copied a law, a journal that published a paper. If the record cannot name the mechanism, the page says so.

That is how you check the mechanism on a route page: find the named thing, check the source, and notice where the path is a guess.
