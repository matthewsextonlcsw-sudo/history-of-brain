# Q03 — How to Read a Route Page

> *A route page is a path. The path shows what the record says about a specific route. The path does not show what the record does not say. That is the point of this page: the route page is a path, and the path is limited.*

## Draft

A route page is a path. The path shows how an idea, a law, or a practice moved from one place or group to another. The path does not show what the record does not say.

A route page is about movement. It does not declare "influence" just because two ideas look alike. It names the mechanism: a person, a ship, a treaty, a journal, a conference. If the record cannot name the mechanism, the page says so.

Start with the Research section. Each fact carries a source. The source tells you where the fact comes from. You can open the source and check it.

Here is a concrete example. Take the Asylum Route. It traces how the asylum became a public institution in Britain. The County Asylums Act of 1808 encouraged justices of the peace to build county lunatic asylums. The 1845 Acts made them compulsory and set up the Lunacy Commission. The 1890 Act widened the role. Those are three dated, named steps. The route page strings them in order and names the law behind each one.

Now check the limits. The route is about Britain. It does not cover how the asylum moved to France, or to the colonies, or to the United States. A route page names the path it traces, and it names the paths it does not.

One more check: the endpoints. A route page names where the path starts and where it ends. The Asylum Route starts in the workhouse and the prison, and it ends in the county asylum. It does not pretend the asylum was the only destination. Some people stayed in the workhouse. Some died in the prison. The route page names the endpoints and the paths that did not lead to the asylum.

One more check: the mechanism. A route page names the mechanism that moved the idea. The Asylum Route names the County Asylums Act of 1808, the 1845 Acts, and the 1890 Act. Those are the mechanisms. Without them, the route is just a list of places. With them, the route is a path.

That is how you read a route page: follow the named mechanism, check each source, and notice where the path ends.
