# Plan: history-of-brain full content draft — H00 start

Depth: tree 3   Mode: orchestrated

Budget note: ~70 pages across 8 start-here pages (H00-H07), 11 time bands
(T00-T10, ~40 focused pages), 12 authority guides (Q01-Q12), 6 lived-
experience streams (V01-V06), 18 regional doors (P01-P18), 12 connection
routes (X01-X12), 9 evidence pages (E01-E09). Each leaf = one page's
research + draft + references. Strong model for all leaves (design/content).
Leaves fan out in waves: H00 first (the landing page gates everything else).

## Contract

- Interfaces: Each leaf writes `content/<zone>/<ID>.md` with three sections:
  `## Research` (key facts + provenance), `## Draft` (page prose), `## References`
  (numbered, full URLs, each tagged Primary / Scholarly / Institutional /
  Reference / Web). One leaf owns one file; no two leaves touch the same file.
- Data ownership: `content/start-here/H*.md`, `content/timebands/T*/*.md`,
  `content/guides/Q*.md`, `content/lived-experience/V*.md`, `content/places/P*.md`,
  `content/routes/X*.md`, `content/evidence/E*.md`. All disjoint.
- Naming: leaf files live at `content/<zone>/<ID>.md`. GATES for each leaf at
  `gates/leaf-<id>.md` (id = lowercase page id, e.g. `leaf-h00.md`).
- Error handling: If a leaf cannot find a primary source for a claim, the
  claim goes in the draft marked `[unverified]` with the gap recorded — never
  silently dropped.
- Shared constraints (from PROJECT-BRAIN.md / Drift Law):
  - No PHI. Ever. Public sources only.
  - Provenance on every fact.
  - Corrections beat additions.
  - Matthew's final editorial sign-off; no editorial changes to protected
    sections of governing docs without him.
